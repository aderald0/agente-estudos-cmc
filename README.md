# Agente de Estudos — Concurso Câmara Municipal de Cuiabá 2026

Aplicativo web estático com **Agente Mentor via API do Gemini** (*Function Calling*) para gerenciar estudos, revisões espaçadas (`1→3→7→15d`), acertos em questões, prova discursiva (20–30 linhas, critério 80/20) e caderno de erros para os cargos de **Analista Legislativo – TI** (manhã) e **Técnico Legislativo** (tarde) no dia **20/12/2026**.

## Como usar gratuitamente
1. Crie uma chave gratuita da **Gemini API** em [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Abra o aplicativo e clique em **Configurar Gemini API** no topo para colar sua chave (ela fica salva apenas no `localStorage` do seu navegador).
3. Converse naturalmente com o agente:
   - *"Bom dia! O que vamos estudar hoje?"*
   - *"Estudei Atos Administrativos por 45 min e acertei 17 de 20 questões."*
   - *"Errei uma questão sobre prazo de veto na Lei Orgânica."*
   - *"Me faça um quiz de 3 questões estilo Selecon sobre Regimento Interno."*
4. *(Opcional)* Para sincronizar automaticamente entre celular e computador gratuitamente, configure um Token com permissão `gist` em **Configurar Gemini API & Gist Sync**.
